# Матричный калькулятор

## Что делает программа?
Программа осуществляет ввод матрицы через консоль, из файла, производит транспонирование, умножение, возведение матрицы в степень, вычисляет определитель, выводит главную диагональ, строку спирали, записывает матрицу в выбранный файл

## Как запустить?
Для запуска достаточно открыть терминал в папке, содержащей matrix_lab и выполнить 
```
python3 -m matrix_lab.main
```

## Пример формата файла ввода матрицы:
```
1 2
3 4
````

где 1 - это количество строк, 2 - количество столбцов, 3 и 4 - значения матрицы. Элементы матрицы могут быть дробных значений.

# Модули:
## Модуль main.py
С помощью него можно выбрать действие для программы. Функции ввода/вывода под пунктами 1, 2 и 9, вычислительные действия с матрицей, такие как транспонирование, умножение, возведение матрицы в степень, вычисление определителя под пунктами от 3-го до 6-го соответственно, и вывод главной диагонали матрицы и матрицы в форме "спирали", представленной одной строчкой под пунктами 7 и 8. При вычислении определителя дополнительно считается время выполнения команды. Пункт 10 отвечает за выход из программы.

## Модуль matrix_ops.py
Этот модуль включает в себя функции различных операций над матрицами (пункты 3-6 и другие), некоторые функции были написаны несколько раз для точного вычисления количества применения функций.

## Модуль matrix_utils.py
Модуль отвечает за ввод/вывод матриц, их отображение, функции статистики, мин. макс. и проверка матрицы так же включены в этот модуль.

## Модуль matrix_io.py
Модуль включает в себя различные генераторы с помощью yield, такие как: построчный вывод, вывод диагонали, по спирали, и чтения матрицы из файла. Генераторы возвращают элементы по одному. а matrices_generator целые матрицы из .txt файлов

## Модуль decorators.py
Декораторы программы представлены в этом файле. Проверка на квадратность матрицы и декоратор таймера.
